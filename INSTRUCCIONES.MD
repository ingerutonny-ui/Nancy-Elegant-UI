# Nancy Elegant UI Kit - Guía de Uso
Gracias por adquirir este componente de alta gama diseñado por **Inge & Tonny Alarcón**.

## Especificaciones Técnicas
- **Estética:** Nancy Elegant (High Legibility).
- **Escalado:** 130% optimizado.
- **Framework:** HTML5 / Tailwind CSS (CDN).

## Cómo usarlo
1. Abre el archivo `index.html` en cualquier navegador.
2. Para integrar con Backend (Python), mapear los campos P1, P2 y P3 en la sección de 'Actividad de Desarrollo'.
3. La tipografía 'Inter' se carga automáticamente vía Google Fonts.

## Soporte
Este kit mantiene la integridad total entre Frontend y visualización de datos.
